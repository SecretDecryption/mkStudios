# MK Studio Cambridge

Vercel-ready website for MK Studio in Cambridge, Ontario.

## Upload through GitHub

1. Create a new private GitHub repository.
2. Open the `mk-studio` folder from this package.
3. Upload everything inside that folder to the repository.
4. Commit the uploaded files to the `main` branch.

## Publish through Vercel

1. In Vercel, choose **Add New → Project**.
2. Import the MK Studio GitHub repository.
3. Keep the detected framework as **Next.js**.
4. Select **Deploy**.

Vercel will rebuild the website automatically whenever the `main` branch is updated.

## Local preview

Install the packages and start the development server:

```bash
pnpm install
pnpm dev
```
